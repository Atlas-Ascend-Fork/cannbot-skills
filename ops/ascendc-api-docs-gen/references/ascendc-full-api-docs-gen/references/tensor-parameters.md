# Tensor 参数表述

仅在目标原型或直接关联类型实际涉及 LocalTensor、GlobalTensor 或 TPosition 时读取；只约束相应参数与成员，不适用于所有 AscendC API。

- 分别记录 Tensor 对象类型、代码明确给出的逻辑位置，以及确有证据的物理存储或数据通路。三者不能仅凭名称互相推导。
- TPosition 的取值及其存储关系来自当前版本的公开定义和实际使用条件，不使用架构白皮书替代接口定义，也不在本文件维护无来源的固定映射表。
- 仅有 LocalTensor 类型而没有具体位置证据时，描述类型即可，不补造 TPosition、Buffer 或搬运通路。
- 非 Tensor 对象、标量、原生指针和 SIMT 接口按自己的原型与公开契约描述，不添加 Tensor 对象的约束。
- 分配、复用、释放和状态恢复要求须由当前接口或示例的实际资源生命周期证明；由框架管理时准确说明管理方。
