# 架构资料使用范围

架构背景仅在解释当前 API 的执行模型、存储或同步术语时按需使用。优先读取用户提供或可核验的对应版本公开资料，记录来源和版本；没有可核验来源时不加入具体容量、带宽、硬件组成或指令能力。

- 产品名称和支持列表以本模块的 [产品规范](product-document-format.md) 为准。
- 架构能力不能证明目标 API 的产品支持、数据类型支持、参数范围或同步要求；这些结论仍需当前接口证据。
- 区分公开架构事实、API 编程抽象和文档写作约定，不把作者的归纳表述为白皮书定义。
- SIMD、SIMT、Tensor 和原生指针等概念只在当前成员实际适用时解释；通用架构背景不要求所有 API 都存在某类对象。

Tensor 参数的具体表述仅在需要时读取 [Tensor 参数表述](tensor-parameters.md)。本文件不随附未经核验的白皮书摘录或规格表。
