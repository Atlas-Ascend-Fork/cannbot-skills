# 官方术语来源

需要核对算子领域术语时，查阅 [Ascend C 官方术语表](https://gitcode.com/cann/asc-devkit/blob/master/docs/zh/guide/technical_appendix/concepts_and_terms/glossary.md)，不维护本地全文副本。

master 链接仅用于发现资料。优先选择对应目标 CANN/源码版本的内容，在 reference-evidence.md 中记录实际来源 URL、版本或提交修订、访问日期和适用范围；可定位时使用固定修订链接。术语资料适用范围未确认时说明限制，不将它当成当前 API 行为或产品支持的证据。来源无法访问时记录缺口，不编造定义。代码中的类型和标识不按词表机械改名。
