# Contraction 术语表

本文件是 contraction 目录的术语与命名约定来源；具体公式、策略及硬件能力仍引用对应模板和接口知识，不在此复制。

## 通用术语

| 术语 | 含义 |
|---|---|
| 保留指标 / 收缩指标 | 前者参与输出坐标，后者在乘积累加后求和消去 |
| M / N / K | 矩阵形执行模板中的输出行、输出列和收缩轴长度；属于模板坐标名 |
| 保留轴坐标 | 输出保留指标的一组坐标；Batch 等模板名描述执行组织，不定义 Contraction 语义类别 |
| baseM / baseN / baseK | Cube 子块尺寸；不是 UB 元素数 |
| kL1 / kAL1 / kBL1 | 单次 L1 数据窗口的原始 K 元素数 |
| blockNum | launch 的 AIC block 数；和有效任务数不必相等 |

## 执行组织与数据范围

“分块”“任务”“数据窗口”分别描述划分规则、调度单位和当前访问范围，并非三个固定嵌套的层级。

| 术语 | 定义与关系 |
|---|---|
| 分块 / 块 | 分块是按轴划分计算或数据范围；块是划分得到的区域。分块尺寸描述计划长度，具体块由起点和有效长度确定 |
| 任务 | 调度器分配给一个核的一份工作，包含输出范围和计算要求。基础模板每个任务计算一个输出块的完整 K；条带任务可以包含多个输出块 |
| 数据窗口 | 某一步搬运或计算实际访问的区域，由所在张量、起点和有效长度确定。按分块尺寸推进窗口；边缘窗口可以小于分块尺寸，驻留窗口可以跨任务复用 |
| SWAT 调度窗口 | 组织任务遍历的一组 M/N 块坐标；属于调度分组，不表示一次搬运范围。沿 M 分组并按确定规则映射，见 [SWAT 调度](generic/swat-scheduler.md) |
| 物理槽 | 承载数据的一份存储空间。不同时间可装入不同数据窗口，同一窗口也可在不同存储层有各自副本 |

例如基础模板的一个任务计算 C 的 128×128 输出块并累加完整 K=640。KL1=256 决定 L1 分块尺寸，依次访问 K 范围 [0,256)、[256,512)、[512,640) 的三个输入数据窗口；KL0=128 再决定每次乘加使用的子窗口。两份 L1 物理槽轮转承载这些窗口，槽数不等于窗口数或任务数。

## 数据布局与命名

| 统一表达 | 含义与使用规则 |
|---|---|
| 数据布局 | 逻辑坐标到存储位置的映射；统一替代“数据排布格式”“Buffer 数据排布格式” |
| 源数据布局 / 目的数据布局 | 搬运两端的数据布局；章节名注明存储层，如“L1 目的数据布局” |
| 物理布局 | 强调实际存储映射时使用，不用于表示逻辑形状 |
| 槽 | “物理槽”的简称；复用受消费者完成约束 |
| 逻辑存活节点 / 物理存活节点 | 分别计数数据角色和同时占用的物理 Buffer 份数 |
| ML1 / NL1 / KL1 / KL0 | 分别为 L1 层 M/N/K 分块长度及 L0 层 K 分块长度，单位为元素；具体实例的地址变量见对应模板 |
| gm2l1 / l12l0 / ... | 数据通路标签；MMAD 表示乘加操作，mmad 用于伪码与甘特图标签；均不表示特定 API 名 |

## 章节与伪代码约定

- 模板章节采用“编号 + 空格 + 标题”；二级标题按 1、2 递增，三级和四级分别使用 1.1、1.1.1，Markdown 层级与编号深度一致。目录路由和术语索引可以不编号。
- Kernel、DAG、Buffer、Tiling 保持大小写；中英文之间留空格。
- 同一含义使用同一术语；源和目的等角色修饰语按实际职责保留。
- 骨架伪代码的标识符、控制流与操作主体使用英文，中文解释放在注释或代码块外。伪操作必须声明不是可调用 API。
- 修改标题时同步维护链接锚点与章节编号引用；不为被删除的汇总章节新增镜像。

## 扩展模板术语

| 统一表达 | 含义与使用规则 |
|---|---|
| ML0 / NL0 | L0 单次输出计算的 M/N 范围，不普遍等于 ML1/NL1 |
| 驻留侧 / 流式侧 | 输入在复用域内保留，或按当前窗口搬入并归还；模板明确是哪一侧 |
| 复用域 | 同一份片上输入保持有效并被重复读取的任务范围；不表示跨核共享 L1 |
| 条带任务 / 输出块 | 条带任务可包含多个 M/N 输出块，每块独立完成完整 K 并写回 |
| 父任务 / 子任务 | 重新切分前后的输出区域；执行子任务时父任务被替换 |
| 矩阵边缘尾块 / 调度尾轮 | 前者来自 M/N 尺寸余数，后者来自任务数相对于核数的余数 |
| Batch 分块 | 按保留轴坐标及 M/N/K 分块计算；各输入的坐标映射独立于块内地址 |
| IterBatch | 一组保留轴坐标分层驻留并逐坐标计算；保留轴不参与收缩 |
| MergeBatch | 合并多个保留轴坐标对应的计算空间后提取各自输出区域；非目标区域不写回 |
| 槽内坐标子区 | 单个物理槽中承载不同保留轴坐标的地址区域；需另列子区数和物理 pitch |

各执行模板的保留轴分块变量、布局跨度函数和索引单位在其 DAG/地址章节定义；公共地址与资源不变量见 [公共契约](generic/common-contract.md)。
