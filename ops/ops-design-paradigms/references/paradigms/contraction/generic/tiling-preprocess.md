# Contraction 范式 Tiling 预处理

本文件将公开计算式归一化为输出保留指标、收缩指标以及各输入的 shape/stride 坐标映射。后续模板使用 [公共契约](common-contract.md) 中的数值、存储、资源与同步不变量。

## 1 问题与设备信息

### 1.1 平台信息

从目标能力绑定获取 SoC、AIC/AIV 核数及 L1/L0/UB 容量，验证取值非零且类型匹配。纯 Cube 执行路径使用 AIC 数，不把 AIV 数代入。记录编译所用 toolkit、接口头文件版本和运行设备；不能从目录或算子名称推定兼容性。

### 1.2 计算式与输入校验

从公开公式提取输出保留指标 `o`、收缩指标 `r` 及两个输入的坐标映射 `phiA(o,r)`、`phiB(o,r)`。逐项校验：

1. 每个输出指标都能映射到输出坐标；每个收缩指标在两输入中对应的维度长度一致，或由公开契约明确允许的广播规则解释。
2. 各输入的逻辑 shape、真实 stride、存储方向和 dtype 分别记录；逻辑转置不代表物理数据已转置。
3. 当前模板要求坐标到地址的映射可由规则 shape/stride 及明确的广播关系表达。依赖动态索引选择、IndexGather 或 Sparse 组织的输入不由当前 Contraction 模板表达。
4. 各输入的物理布局和 padding 按公开契约与目标能力计算；不能以逻辑元素数替代物理字节数。

各输入分别计算物理存储字节数，包括其自身维度，而不是广播后的输出维度。文件读取、分配和 H2D 使用一致的物理字节数；checked 乘法避免尺寸溢出。输出以自身 dtype 和 layout 契约为准。

输出为空时按框架约定完成空输出，不发起 `blockDim=0` 的非法 launch。收缩域为空而输出非空时，核心结果写零；若装配 Bias[N] 组合扩展，则再按组合扩展契约产生偏置结果，不能漏写输出。

### 1.3 值依赖分析

若 Host Tiling 需要读取输入值，依照[值依赖规则](../../common/value-depend-process.md)完成声明及数据获取；若所选接口由 Device 消费输入值，保留其 Device ABI，不擅自移至 Host，也不将运行时数据视为静态常量。当前 Contraction 模板不定义按动态索引表选择输入矩阵的值依赖路径。

## 2 指标归一化与合并

按公开公式保留指标顺序，并为两个输入分别生成从输出/收缩坐标到物理地址的映射。只有在连续性、stride、广播关系及指标次序均保持时，才可合并相邻指标；不得仅凭元素总数相同而 reshape。

矩阵形模板使用 `A[M,K]`、`B[K,N]`、`Y[M,N]` 作为坐标实例，其中 M/N 是保留轴，K 是收缩轴。含前导保留轴时，逐轴保存输出坐标到各输入的映射。比如 `A[2,1,M,K]` 与 `B[1,3,K,N]` 对应输出前缀 `[2,3]`；映射到 A 的第二个前导轴时坐标固定为 0，映射到 B 的第一个前导轴时坐标固定为 0。展平前必须证明每个输入的物理步长和广播映射仍等价。

## 3 归一化结果校验

逐个或按边界抽样枚举归一化前后的输入地址，核对同一输出坐标及收缩坐标取得的元素与原始公开公式一致。检查 shape、stride、归一化指标顺序、空维处理和可能的广播轴；此处不进行 L1/UB 资源切分。

## 4 Elementwise/Broadcast Bias[N] 组合扩展输入

Bias 作为可选组合扩展输入接入矩阵形模板。组合扩展输入必须是一维 `[N]`，其唯一变化轴对应输出的 N 轴；沿其他输出轴广播。按公开接口校验 shape、dtype 和 N 方向真实 stride，不扩展为多维、矩阵 bias 或任意广播 shape。

组合扩展存在时，Tiling 将当前输出任务的 N 区间映射到同一 Bias[N] 向量，并为组合扩展数据和转换预留实际资源；无组合扩展时不读取 bias 描述或地址。若收缩域为空，核心结果为零，组合扩展仍按 `Y[...,m,n]=convert_out(bias[n])` 写出有效结果。组合扩展语义引用 [公共契约 §6.2](common-contract.md#62-可选-bias-的语义与数值)；首段融合仅是执行策略，不改变输入契约。
